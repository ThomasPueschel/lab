# Püschel Lab Website

Quarto website for the Comparative Evolutionary Anthropology lab, University of Oxford.

## Local development

```bash
# Install Quarto: https://quarto.org/docs/get-started/
quarto preview
```

## Deployment

Push to `main` — GitHub Actions automatically renders and deploys to GitHub Pages.

Before first deploy:
1. Create a GitHub repo named `lab` under your account (ThomasPueschel)
2. Enable GitHub Pages → Source: GitHub Actions (in repo Settings → Pages)
3. Push this folder as the repo

Site will be live at: https://ThomasPueschel.github.io/lab
